# EstateIQ Project Scope

This document outlines the main product modules planned for the EstateIQ platform.

## Auth

Handles user authentication and access control.

- User login and logout
- Role-based access for different user types
- Session and token management

## Properties

Covers property listing, property details, and property data management.

- Property creation and editing
- Property search, filters, and listing views
- Detailed property information and status tracking

## Dashboard

Provides an overview of key platform data and user activity.

- High-level KPIs and summary cards
- Recent activity and quick insights
- Entry point for operational workflows

## Notifications

Supports communication and alerts inside the platform.

- In-app notifications
- Status updates and reminders
- Event-driven user alerts

## ML Prediction

Represents the machine learning features used for property-related predictions.

- Price or value prediction
- Predictive insights based on property data
- ML result presentation for users

## Map

Supports map-based browsing and location context for properties.

- Property visualization on a map
- Area and location-based exploration
- Geographic context for decision-making

## Favorites

Allows users to save and revisit selected properties.

- Save and remove favorite properties
- Personal shortlist management
- Quick access to preferred listings
